DEPLOY AS A STATIC WEBSITE

Upload the entire presentation-package folder to any static host. Keep all
subfolders unchanged and set index.html as the default page.

Quick options:

- Netlify: drag this folder into Netlify Drop.
- Cloudflare Pages / Vercel: create a static project with this folder as the
  root; no build command is required and the output directory is ".".
- Nginx / Apache: copy the folder contents into the site's document root.

Required server behavior:

- Serve .html, .jpg and .png files normally.
- Do not flatten or rename the presentation-assets and frontend subfolders.

Files referenced by the deck (must be uploaded):

- index.html
- presentation-assets/book-tavern/printway-book-tavern.jpg (slide 4 demo image)
- frontend/public/sponsors/event-logo-header.png (fixed header logo)
- frontend/public/sponsors/event-logo-horizontal.png (cover logo)

The assets-gen subfolder is no longer referenced by any slide; it can be
omitted from the upload if you want the smallest possible package.

After deployment, open the site root. Verify slide 1 shows both event logos,
slide 4 displays the Printway Book Tavern Sign image with the EN/VI/TH/ID locale
pack, and Google Fonts load (Space Grotesk / Inter) when online.
