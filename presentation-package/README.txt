THỢ CỐT — PRESENTATION PACKAGE

Recommended way to present on macOS:

1. Double-click start.command.
2. Open http://127.0.0.1:4173/ if the browser does not open automatically.
3. Press F for fullscreen.
4. Use Left/Right arrows or Space to change slides.

The folder contains every local image, logo and video used by the deck.
Google Fonts are loaded from the internet; system-font fallbacks are used when offline.

For deployment, upload this entire folder without changing its internal structure.
The server should use index.html as the default document. See DEPLOY.txt.
